## Publication

**Waghmare, R. (2026).** *CHURI: Contour-Gated, Resource-Intelligent Retail Tracking System.* IEEE/CVF WACV Workshops, pp. 1574–1581. Sole author. [Read the paper](https://openaccess.thecvf.com/content/WACV2026W/PRAW/papers/Waghmare_CHURI_Contour-Gated_Resource-Intelligent_Retail_Tracking_System_WACVW_2026_paper.pdf)

The field was compressing accurate models onto cheap hardware. I asked the inverse question: given the budget, what is the smallest system that still works? Eight cameras on one $80 device instead of two, with detection accuracy 26 percentage points higher than the standard approach.
